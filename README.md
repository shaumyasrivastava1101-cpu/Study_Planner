# Smart Study Planner 📚

A clean, browser-based **Smart Study Planner** built with **HTML**, **CSS**, and **JavaScript** to organize daily study tasks, track mock tests, and monitor overall study progress.

## 🔗 Live Demo
Open the live web app directly in your browser:  
**[Launch Smart Study Planner](https://shaumyasrivastava1101-cpu.github.io/Study_Planner/)**

## ✨ Features
- **Task Management:** Add, organize, and track daily study tasks and goals.
- **Mock Test Tracker:** Log mock test scores and monitor performance over time.
- **Progress Tracking:** View completion status and stay consistent with study targets.
- **Zero Setup Required:** Runs directly in any modern web browser from a single `index.html` file.

## 🛠️ Built With
- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
